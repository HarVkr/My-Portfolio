# PRD — HARSHAL: Cinematic Personal Portfolio

## Original Problem Statement
Build a premium, cinematic personal portfolio website for Harshal Vhatkar, conceived as a personal streaming-platform experience (not a Netflix clone, not a generic dev portfolio). Initial implementation covers the full entry experience only: (1) Hello handwriting animation, (2) HARSHAL identity reveal, (3) "Who's Watching?" profile selection (3 profiles), (4) shared featured hero with per-profile intro content. Later portfolio sections are explicitly out of scope for this phase.

## User Personas
- **Visitor / curious friend** — explores the full "Meet Harshal" story.
- **Recruiter / hiring manager** — wants experience, education, skills, achievements fast.
- **Collaborator / client** — interested in product thinking, engineering and creative work.

## Core Requirements (static)
- Palette: #090909 / #171719 / #B51F32 / #D33B4C / #E7E2DF / #A7A2A0; crimson used selectively as light, not surfaces.
- Typography: Dancing Script (hello only), Clash Display (display), DM Sans (body) — all self-hosted with licences kept in `public/licenses/`.
- Genuine handwriting reveal (SVG path stroke-draw), not typewriter/fade.
- Skip intro, once-per-session intro (user choice), browser back works, reduced-motion respected.
- Strict scope: no other sections, no fake stats, no stock portraits, no Netflix branding.

## Architecture
- React (CRA + craco) SPA, react-router v7 with route-level AnimatePresence crossfades.
- Routes: `/` (hello → identity orchestrator), `/profiles`, `/profile/:profileId` (shared hero, config-driven).
- Content lives in `src/config/profiles.js`; design tokens in `src/index.css` + `tailwind.config.js`.
- Framer Motion for all sequencing; no new runtime dependencies added.
- Build-time asset pipeline: `scripts/generate_hello_paths.py` (fontTools + uharfbuzz) bakes real Dancing Script glyph contours (wght 500) into `src/data/helloPaths.js`.
- Backend untouched (FastAPI health only); no data layer needed this phase.

## Known Limitations
- Handwriting animation draws each glyph's true contours (outline-draw that fills in) — the standard technique for real fonts; a single-line pen-stroke look would require a monoline script or hand-skeletonized paths.
- EXPLORE MY WORK scrolls to Your Next Watch; VIEW RESUME opens the chooser (view in new tab / download PDF). No further placeholder toasts remain.
- Intro is once per session by user choice; clear sessionStorage key `harshal:intro-seen` to replay.
- Tool icons are monochrome (palette-driven), not brand-colored, to keep the obsidian/crimson aesthetic.
